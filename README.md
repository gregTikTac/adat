# Адат: прототип главного экрана туроператора

Первый экран сайта туроператора гостеприимства «Адат» (Махачкала). Цвета и шрифты из брендбука «АДАТ версия 5».

## Что внутри

- **Hero.** Сцены пока нарисованы кодом (SVG) как заглушки; на следующем этапе их заменят кавказские виды. Шкала внизу управляет временем суток в выбранной точке Дагестана.
- **Пять маршрутов из Махачкалы:** Сулак (каньон и Сарыкум), Дербент, Гуниб, Хунзах, Гоор. Солнце считается по реальным координатам. Кнопка «Сейчас» показывает местное время и температуру.
- Время рассвета и заката, дорога от Махачкалы, лучший сезон (май – октябрь).
- Заявка «Подобрать тур»: форма, серверная валидация, точка для CRM.
- Адаптивная вёрстка, клавиатура, `prefers-reduced-motion`.

## Запуск

```bash
npm install
npm run dev -- -p 43127      # режим разработки
npm run build && npm start   # production
```

Открыть: <http://localhost:43127>

## Как подставить бренд

- Цвета: `src/app/globals.css` (блок `--brand-*`).
- Шрифты: `src/app/layout.tsx` (Ysabeau + Tenor Sans).
- Название, меню, тексты hero, телефон: `src/config/brand.ts`.
- Маршруты: `src/data/destinations.ts`.

## Бэкенд

- `POST /api/lead`: проверяет заявку (zod). Если задана `LEAD_WEBHOOK_URL`, пересылает JSON в CRM. Без неё заявка пишется в лог сервера.
- `GET /api/weather?id=sulak`: температура воздуха (и воды у Сулака/Дербента) через Open-Meteo, кэш 15 минут.

## Стек

Next.js (App Router), TypeScript, Tailwind CSS 4, shadcn/ui, motion.
