# Meridian: прототип главного экрана туркомпании

Брендонейтральный шаблон первого экрана сайта туроператора. Название, цвета и шрифты временные: их заменят, когда придёт брендбук.

## Что внутри

- **Hero без фото и видео.** Сцены нарисованы кодом (SVG), поэтому прототип выглядит дорого сразу, без покупки стоковых материалов. Позже сцену можно заменить фото или видео, остальной интерфейс не изменится.
- **Фирменная особенность: «Сутки там».** Пять направлений (Мальдивы, Дубай, Бали, Стамбул, Пхукет). Шкала внизу управляет временем суток в выбранной точке мира. Положение солнца и луны считается по реальным координатам и дате, поэтому цвет неба, свет в окнах, звёзды и блик на воде соответствуют настоящему моменту. Кнопка «Сейчас» показывает, что происходит там прямо сейчас, вместе с температурой воздуха и воды.
- Время рассвета и заката, маршрут от Москвы с расстоянием, лучший сезон (с отметкой текущего месяца).
- Заявка «Подобрать тур»: форма, серверная валидация, готовая точка для CRM.
- Адаптивная вёрстка, управление с клавиатуры, учёт `prefers-reduced-motion`.

## Запуск

```bash
npm install
npm run dev -- -p 43127      # режим разработки
npm run build && npm start   # production
```

Открыть: <http://localhost:43127>

## Как подставить бренд

- Цвета: `src/app/globals.css` (блок `--brand-*`).
- Шрифты: `src/app/layout.tsx` (две переменные: основной и заголовочный).
- Название, меню, тексты hero, телефон: `src/config/brand.ts`.
- Направления, часовые пояса, сезоны, тексты: `src/data/destinations.ts`. Это заглушки, их заменят реальными предложениями.

## Бэкенд

- `POST /api/lead`: проверяет заявку (zod). Если задана переменная `LEAD_WEBHOOK_URL`, пересылает JSON в CRM (amoCRM, Bitrix24, n8n, Telegram-бот). Без неё заявка пишется в лог сервера.
- `GET /api/weather?id=maldives`: температура воздуха и воды через Open-Meteo (без ключа), кэш 15 минут. Если сервис недоступен, отдаёт средние значения.

## Стек

Next.js (App Router), TypeScript, Tailwind CSS 4, shadcn/ui, motion.
